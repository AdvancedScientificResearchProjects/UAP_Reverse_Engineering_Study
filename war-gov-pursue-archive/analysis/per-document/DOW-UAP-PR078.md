## Summary / Резюме

A 4-minute-58-second infrared-sensor clip — **part 2 of 2 of a single 2 November 2020 multi-clip encounter** in the USCENTCOM AOR, paired with [`DOW-UAP-PR077`](DOW-UAP-PR077.md). The clip durations are identical (298 s for both PR077 and PR078) and the AARO Video Description timelines are **prose-identical**: same single-target track 00:00–03:21 with intensity growing throughout, same second-target transit 03:15–03:17 at top-right, same inter-target pan 03:22–04:58. The file sizes differ (~81 MB for PR077, ~73 MB for PR078) — a ~10% size delta consistent with two independently encoded files of the same nominal duration but slightly different IR scene content (i.e. not the same file uploaded twice).

**RU:** 4-минутный 58-секундный клип инфракрасного сенсора — **часть 2 из 2 одного многоклипового события 2 ноября 2020** в зоне ответственности USCENTCOM, в паре с [`DOW-UAP-PR077`](DOW-UAP-PR077.md). Длительности клипов идентичны (298 с для PR077 и PR078), а таймлайны описания видео AARO **прозаически идентичны**: то же одноцелевое слежение 00:00–03:21 с возрастающей интенсивностью, тот же транзит второй цели 03:15–03:17 в верхнем-правом, та же межцелевая панорама 03:22–04:58. Размеры файлов различаются (~81 МБ для PR077, ~73 МБ для PR078) — дельта размера ~10%, согласующаяся с двумя независимо кодированными файлами одной и той же номинальной длительности, но слегка различающегося ИК-содержимого сцены (т.е. это не один файл, загруженный дважды).

PR078 is therefore the **second-platform feed** of the same encounter — analytically inseparable from PR077, but a meaningful independent data point because dual-sensor confirmation rules out single-sensor artefacts (gain artefacts, optical pollution, single-turret calibration drift) that could explain a one-platform track.

**RU:** Комбинация (а) двух токенов `[CALLSIGN]` в каждом заголовке, (б) двух различных DVIDS-активов идентичной длительности, (в) побитно идентичных прозаических таймлайнов AARO для обоих клипов и (г) явного вмешательства AARO «не дубликаты» лучше всего объясняется как **две платформы, одновременно наблюдающие и отслеживающие то же UAP-событие**, при этом ИК-поток каждой платформы опубликован как собственная PR-запись. A true dual-platform pair will show parallax; a sequential-pass-of-same-platform pair will not. This is the single most diagnostic resolvable analysis for the PR077/PR078 hypothesis.

   **RU:** Покадровый тест параллакса: показывает ли PR078 ту же геометрию цели на тех же временных отметках, что и PR077, или есть **сдвиг параллакса**, согласующийся с другой позицией платформы? Истинная двухплатформенная пара покажет параллакс; пара последовательных проходов одной платформы — нет.
2. Does PR077/PR078 pair with a specific CENTCOM MISREP D-record for 2 November 2020? A dual-platform 5-minute encounter would normally generate a substantive MISREP. See pairing-inventory framework in [`region-centcom-2013-2026.md`](../topical/region-centcom-2013-2026.md).

   **RU:** Сопоставляется ли PR077/PR078 с конкретной MISREP D-записью CENTCOM на 2 ноября 2020? Двухплатформенное 5-минутное событие обычно породило бы существенный MISREP.
3. Why did AARO release as two separate files of nearly identical duration rather than as one merged composite (cf. `DOW-PR22`'s IR+EO split-screen format)? Is this because the original sensor archive stored each platform feed as its own file and AARO declined to re-encode, or an editorial choice to preserve dual-source provenance over presentation convenience?

## Notes / Замечания

- **PR078's analytic weight is inseparable from PR077 / Аналитический вес PR078 неотделим от PR077:** reading PR078 in isolation loses the dual-sensor framing entirely. The clip is meaningless as a one-off record but materially significant as the second half of a paired dual-platform release. The card pairing convention here (PR077 ↔ PR078) should be enforced in all cross-reference contexts.
- **AARO's "not duplicates" comment is unique in the R02 PR-cluster reviewed / Комментарий AARO «не дубликаты» уникален в обзорной R02 PR-кластере:** the explicit editorial intervention warns analysts not to dismiss the second file as a duplicate upload. AARO would only need this caveat if (a) the prose timelines are indeed identical (they are) and (b) the analytic value depends on the analyst treating the two as distinct. This is editorially significant — AARO is preserving an analytical claim about the structure of the encounter, not just dumping files.
- **Independent encoding confirmed by size delta / Независимое кодирование подтверждено дельтой размера:** PR077 = ~81 MB, PR078 = ~73 MB at identical 1920×1080 and 298 s. The ~10% file-size delta would not occur for the same source file encoded twice with the same codec settings; it indicates the two files contain materially different pixel content despite covering the same described events. Strong file-level corroboration of AARO's "not duplicates" claim.
- **Dual-platform interpretation has strong forensic-physics implications / У двухплатформенной интерпретации сильные судебно-физические следствия:** if PR077/PR078 is confirmed as dual-platform via parallax analysis, it joins a very small set of multi-sensor UAP captures in the released US government corpus where prosaic single-sensor artefact explanations are eliminated. Combined with the on-record intensity-growth claim (3 m 21 s of progressively brightening IR signature), the encounter starts to resemble a sustained-track multi-witness multi-sensor case rather than a single fleeting sensor blip.
- **Editorial format choice — two clips vs one merged file / Редакторский выбор формата:** PR077/PR078 demonstrates an alternative release pattern from R01's `DOW-PR22` (IR + EO split-screen in one file). The PR077/PR078 format is provenance-preserving (each platform's file is independently auditable) but UX-hostile (analysts must know to read them together). May reflect original sensor-file format constraints rather than AARO editorial preference.
