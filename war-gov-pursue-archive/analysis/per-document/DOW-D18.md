## Summary / Резюме

USCENTCOM AFCENT MQ-9 Reaper sortie of **482 ATKS** out of **OKAS (Ali Air Base / Tallil, southern Iraq)** on **1 December 2022**, tasked under **OP INHERENT RESOLVE** in support of **TF [redacted]** for target development around an objective IVO **Baghdad, Iraq**. Mission profile: **19 h 17 min** total mission, **18 h 35 min** on station; FMV via **AN/DAS-class** targeting pod, **AIRHANDLER + BLASPHEMY** SIGINT (AH/BLASPHEMY — "BLASPHEMY" is an explicit codename for a SIGINT enhancement / processing variant in the AIRHANDLER family). Mission Type: **TARGET DEV** (Target Development).

The narrative documents continuous Pattern-of-Life ISR ("CONDUCTED SCANS FOR HVI/POI, POL, ADMS IN SUITS, WEAPONS, CONVOYS/SENTRY, AND PERSONNEL [redacted]") for ~9 hours from 1518Z to 0426Z, in support of TF [redacted] for OP [redacted] / OBJ [redacted] IVO Baghdad. In the middle of this ISR window, the UAP event:

> "AT 1620Z, [redacted] OBSERVED 1X POSSIBLE UAP/UAV FLYING WEST TO EAST IVO 38SMB4[redacted] 83[redacted]. [redacted] DID NOT FOLLOW UAP. [redacted] CONTINUED THE MISSION AS TASKED, NO FURTHER EVENTS WERE OBSERVED."

UAP block fields: Initial Contact DTG **011620:00ZDEC22**, MDS Type / Asset Type `1.4a, 1.4g` masked, Tail Number `1.4a, 1.4g` masked, Friendly Aircraft Location `38S MB 4[redacted] 8[redacted]`, Friendly Aircraft Altitude/Depth **FL180**, Number of UAP Sighted **1**, UAP Signatures **No**, UAP Effects on Persons **NONE REPORTED**, UAP First Seen Location `38S MB 4[redacted] 83[redacted]` (i.e. essentially the same grid as the friendly aircraft).

This is a **single, brief UAP/UAV contact directly co-located with the Reaper's own orbit** (UAP grid ≈ friendly aircraft grid, both `38S MB 4[redacted] 83[redacted]`). The operator characterised the contact as a **possible UAP or UAV** — the explicit "/UAV" qualifier indicates the screener considered "unmanned aerial vehicle" (i.e. a conventional drone) as a primary candidate explanation. The operator **explicitly chose not to follow** ("DID NOT FOLLOW UAP. CONTINUED THE MISSION AS TASKED") — preserving on-station time for the higher-priority TF target-development tasking. This is the corpus's clearest example of the **mission-priority disposition**.

**RU:** Вылет MQ-9 Reaper из **482 ATKS** с базы **OKAS (Али / Талиль, южный Ирак)** 1 декабря 2022 года по OP INHERENT RESOLVE в поддержку **TF [засекречено]** по разработке целей IVO **Багдад, Ирак**. Продолжительность миссии: **19 ч 17 мин**, время на станции: **18 ч 35 мин**; FMV через турель AN/DAS-класса, SIGINT через **AH/BLASPHEMY**. Тип миссии: **TARGET DEV**.

В ходе 9-часового ISR-наблюдения за обстановкой произошло событие с НЛО: **"AT 1620Z, [засекречено] OBSERVED 1X POSSIBLE UAP/UAV FLYING WEST TO EAST IVO 38SMB4[засекречено] 83[засекречено]. [засекречено] DID NOT FOLLOW UAP. [засекречено] CONTINUED THE MISSION AS TASKED."** Это **единственный кратковременный контакт с НЛО/БАС**, непосредственно совпадающий с орбитой Reaper. Оператор явно **не стал преследовать** контакт, сохранив время на станции для более приоритетного задания TF. Наиболее явный пример **диспозиции приоритета миссии** в корпусе.
