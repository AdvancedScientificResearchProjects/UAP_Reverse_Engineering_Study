## Notes / Замечания

- **Three-object fixed-formation — phenomenologically distinctive / Фиксированное построение трёх объектов — феноменологически характерно:** PR47 is one of very few PURSUE records describing multiple co-moving objects with rigid relative geometry. CENTCOM events are overwhelmingly single-target. This makes PR47 morphologically aligned with PR46 (single object with multi-element structure) — both INDOPACOM 2023-2024 records describe multi-feature targets. / PR47 — одна из очень немногих записей PURSUE, описывающих несколько совместно движущихся объектов с жёсткой относительной геометрией. События CENTCOM подавляющим образом являются однопелевыми.
- **Rigid relative geometry — interpretive ambiguity / Жёсткая относительная геометрия — неоднозначность интерпретации:** the rigid 3-feature configuration over 2 minutes admits three quite different explanations: (a) **Single physical object with three appendages** — possibly the same morphology class as PR46's "football with three radial projections"; (b) **Three independent objects in formation** — aircraft formation flying, drones in coordinated geometry, or birds in V-formation; (c) **Optical artifact** — three diffraction lobes or three reflections of a single bright source within the IR turret optics. / Жёсткая конфигурация 3 признаков на протяжении 2 минут допускает три совершенно разных объяснения: (a) единственный физический объект с тремя придатками; (b) три независимых объекта в строю; (c) оптический артефакт.
- **Sensor / Сенсор:** "infrared sensor" generic; INDOPACOM 2023 ISR platform identity not disclosed. / "Инфракрасный сенсор" — обобщённо; идентичность платформы ISR INDOPACOM 2023 не раскрыта.
