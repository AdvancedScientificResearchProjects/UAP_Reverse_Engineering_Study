## Notes / Замечания

- **Range Fouler report — terminology distinction / Отчёт Range Fouler — терминологическое различие:** "Range Fouler" is the U.S. Navy / NAVCENT term for objects that intrude into a designated training/exercise range — sortie-distinct from a generic CENTCOM mission report (MISREP). PR36 is the only PR record paired with a Range Fouler product. This implies the D38 sortie was a Navy-supported (NAVCENT) event rather than a Joint AOC-tasked AFSOC ISR sortie. / "Range Fouler" — термин ВМС США / NAVCENT для объектов, вторгающихся в назначенный учебный/учений полигон — отличается по типу вылета от общего доклада о миссии CENTCOM (MISREP). PR36 — единственная PR-запись, сопряжённая с продуктом Range Fouler.
- **Erratic motion + reticle fail to lock / Хаотичное движение + неспособность прицела захватить:** the combination of the operator observing "erratic movements above the water" with the auto-track reticle's inability to acquire is suggestive of either (a) an IR signature too small/dim to feed the auto-track algorithm, or (b) motion exceeding the auto-track's slew-rate threshold. The 55-second manual track that succeeded earlier argues against (a), pointing toward (b) — fast-maneuvering target outpacing auto-track reticle. / Сочетание наблюдения оператором "хаотичных движений над водой" с неспособностью прицела авто-трека захватить цель предполагает либо (a) слишком малую/тусклую ИК-сигнатуру, либо (b) движение, превышающее пороговое значение скорости вращения авто-трека.
- **Long-duration 2020 clip / Длинный клип 2020:** at 2:17, PR36 is one of the longest 2020 PR clips (PR42 4:53, PR44 5:11 are longer; PR41 1:34 is shorter). / При 2:17 PR36 — один из длинных PR-клипов 2020.
