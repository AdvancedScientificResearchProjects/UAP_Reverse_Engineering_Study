# PURSUE Release 01 — Document Typology / Типология документов PURSUE Релиз 01

A taxonomy of the 161 records by document kind and provenance pattern. Each type has distinct evidentiary value, redaction pattern, and analytical handling.

**RU:** Таксономия 161 записи по виду документа и паттерну происхождения. Каждый тип имеет отличительную доказательную ценность, паттерн редакций и аналитическую обработку.

## 1. Mission Reports (MISREP) — DoW D-series / Рапорты о миссиях (MISREP) — D-серия DoW

**Count / Количество:** ~22
**Source code prefix / Префикс кода источника:** `DOW-D{n}` (D3–D55, with gaps / с пропусками)
**Format / Формат:** Standardized U.S. military reporting form. Used by services to document operational events. Frequently used to forward UAP observations to AARO. / Стандартизированная форма военной отчётности США. Используется службами для документирования оперативных событий. Часто применяется для передачи наблюдений НАЯ в AARO.
**Key fields / Ключевые поля:** GENTEXT narrative, location/time, platform, sensor data, qualitative observations. / Нарратив GENTEXT, местоположение/время, платформа, данные датчиков, качественные наблюдения.
**Redaction pattern / Паттерн редакций:** Witness identities, base locations, military details redacted; phenomenology descriptions explicitly preserved per release policy. / Личности свидетелей, местоположения баз, военные детали редактированы; описания феноменологии явно сохранены согласно политике выпуска.
**Examples / Примеры:**
- DOW-D33 — Greece, October 2023 (90° turn at 80 mph, sea-skim mode) / Греция, октябрь 2023 (поворот 90° на 80 миль/ч, режим бреющего полёта над морем)
- DOW-D55 — Latakia, Syria, November 2016 (P-8A vs object, 500 kn) / Латакия, Сирия, ноябрь 2016 (P-8A против объекта, 500 узлов)
- DOW-D18 — Iraq, December 2022 (single observer, no pursuit) / Ирак, декабрь 2022 (единственный наблюдатель, без преследования)

## 2. Unresolved/Pending Reports (PR) — DoW PR-series / Нерешённые/ожидающие отчёты (PR) — серия PR DoW

**Count / Количество:** 28 (PR19–PR49)
**Source code prefix / Префикс кода источника:** `DOW-PR{n}`
**Format / Формат:** Mostly IR sensor B-roll videos (5 sec – 3 min) hosted on DVIDS, with companion MISREP-like PDF in some cases. / В основном B-roll видео с ИК-датчиков (5 сек – 3 мин) на DVIDS, в некоторых случаях с сопутствующим PDF типа MISREP.
**Boilerplate disclaimer / Стандартная оговорка:** "for informational purposes only … should not interpret as analytical judgment." / «только в информационных целях … не следует интерпретировать как аналитическое суждение».
**Geographic concentration / Географическая концентрация:** CENTCOM (Arabian Gulf, Strait of Hormuz, Iraq, Syria, Gulf of Aden), AFRICOM (Djibouti), INDOPACOM (East China Sea), Greece, UAE. / CENTCOM (Персидский залив, Ормузский пролив, Ирак, Сирия, Аденский залив), AFRICOM (Джибути), INDOPACOM (Восточно-Китайское море), Греция, ОАЭ.
**Examples / Примеры:**
- DOW-PR34 — Greece, 2023 (paired with D33; 2:57 IR-tracked) / Греция, 2023 (в паре с D33; 2:57 ИК-отслеживание)
- DOW-PR43 — Africa, 2025 / Африка, 2025
- DOW-PR49 — Department of the Army, January 2026 (newest record in release) / Министерство армии, январь 2026 (новейшая запись в релизе)

## 3. FBI Master Case File 62-HQ-83894 "Flying Discs" / Основное дело FBI 62-HQ-83894 «Летающие тарелки»

**Count / Количество:** 17 PDFs (10 sections + 7 serials + Sub_A)
**Source code prefixes / Префиксы кода источника:** `FBI-62HQ-S{nn}` (sections / разделы), `FBI-62HQ-Sr{n}` (serials / серийные), `FBI-62HQ-SubA`
**Period covered / Охватываемый период:** 1947–1968
**Provenance claim / Заявление о происхождении:** war.gov states this is "complete case file with several newly declassified pages and only minor redactions" vs. heavier-redacted FBI Vault version. / war.gov заявляет, что это «полное дело с несколькими новыми рассекреченными страницами и лишь незначительными редакциями» в сравнении с более сильно редактированной версией FBI Vault.
**Notable contents / Примечательное содержание:**
- Oak Ridge TN photographic evidence / Фотографические свидетельства Оук-Ридж, ТН
- Technical proposals on propulsion (Track 7 cross-link candidate) / Технические предложения по двигательной установке (кандидат перекрёстной ссылки Track 7)
- Witness testimonies and public reports / Показания свидетелей и публичные отчёты
- Investigative records / Следственные материалы

Most metadata files share an identical corpus-level description, so per-section content distinctions must be derived from OCR'd transcripts.

**RU:** Большинство файлов метаданных разделяют идентичное описание уровня корпуса, поэтому различия содержания по разделам должны быть извлечены из OCR-транскриптов.

## 4. FBI Western US 2025 IR Photo Cluster / Кластер ИК-фото FBI Западный US 2025

**Count / Количество:** 32 PDFs (8 A-series + 24 B-series, plus 8 standalone JPG thumbnails / плюс 8 автономных JPG-миниатюр)
**Source code prefix / Префикс кода источника:** `FBI-IR-A{nn}` / `FBI-IR-B{nn}`
**Format / Формат:** Monochrome IR captures with crosshair reticle overlay; documented as PDFs (not raw images). Каждый содержит стандартное техническое примечание о несброшенной дате/времени системы.
**Notable / Примечательно:** B7 shows a helicopter in upper-right with smaller object below the reticle — likely the "ground pursuit" subject of the USPER 302 statement. / B7 показывает вертолёт в правом верхнем углу и меньший объект ниже прицельной сетки — вероятно, «наземное преследование», предмет заявления USPER 302.
**A-series / Серия A:** general locations marked N/A. / общие местоположения помечены N/A.
**B-series / Серия B:** Western United States. / Западные Штаты США.

## 6. NASA Spaceflight Records / Записи NASA о космических полётах

Other items are historical curation. / VM6 (треугольное построение Apollo 17) активно расследуется DoW; хранение оригинальной плёнки передано. Остальные элементы — историческое курирование.
